# Perfume Product Card 

This is a responsive **product card component** for a luxury perfume, built using pure HTML and CSS. It features:

- Elegant fonts (Montserrat, Fraunces, Playfair Display)
- Responsive layout with media queries
- Custom button with Font Awesome icon
- Beautiful mobile adaptation
- Clean, semantic HTML and modular CSS

- CSS3  
- Google Fonts

- Fully responsive (adapts to all screen sizes)

- Stylish button hover effects
- Consistent padding and spacing
